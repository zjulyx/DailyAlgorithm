## 题目描述

社团共有 num 位成员参与破冰游戏，编号为 0 ~ num-1。成员们按照编号顺序围绕圆桌而坐。社长抽取一个成员 target，从 0 号成员起开始计数，排在第 target 位的成员离开圆桌，且成员离开后从下一个成员开始计数。请返回游戏结束时最后一位成员的编号。

### 示例 1：

- 输入：num = 7, target = 4
- 输出：1

### 示例 2：

- 输入：num = 12, target = 5
- 输出：0

### 提示：

- 1 <= num <= 10^5
- 1 <= target <= 10^6

## 题目思考

1. n 个成员开始游戏和 n-1 个成员开始游戏时, 最后剩下的成员之间有什么关系吗?

## 解决方案

#### 思路

- 为了方便描述, 假设总成员有 N 个, 目标是 M. 一个比较容易想到的思路是暴力法, 即使用数组模拟整个过程: 记录当前起点, 求要离开的下个成员的编号, 并从原列表中移除它. 但这样时间复杂度达到了 O(N^2), 因为移除元素也需要 O(N) 时间
- 而改用双端链表的话则为 O(MN), 因为虽然移除变为了 O(1), 但每次定位下一个要离开的成员编号时不能像数组那样 O(1) 时间定位, 而是需要 O(M) 时间来遍历到下个移除的位置
- 那有什么方法可以做到更小的时间复杂度呢?
- 如果我们能从 n-1 个成员的结果, 推导出 n 个成员的结果, 那就可以一次遍历 O(N) 时间搞定
- 所以尝试动态规划的思路, 设`dp[n, m]`是 n 个成员时每次删除第 m 个成员的最后剩下成员的编号
- 第一次删除时, 删除成员的编号 i 为`(m-1)%n`, 而其下一个编号 i+1 为下一次删除的起点
- 此时将新的起点 i+1 映射为编号 0, 自然 i+2 就对应编号 1, ... 到最后原编号 i 就对应映射编号 n-2. 这样就转换成了 n-1 个成员时每次删除第 m 个成员的情况
- 显然映射编号 x 与原编号 y 的关系是 `y = (x+i+1)%n`, 而 i 为`(m-1)%n`, 所以可以进一步得到`y = (x+m)%n`
- 编号映射之后, 此时总共有 n-1 个成员, 最终剩余的成员就是 `dp[n-1,m]`, 这个是映射编号, 根据上面的编号转换关系, 反推出原编号就是`(dp[n-1,m]+m)%n`
- 而不管是第一次删除还是第二次删除, 其最终剩余的成员只能是同一个, **所以`dp[n, m] = (dp[n-1,m]+m)%n`, 这就是最核心的状态转移方程**
- 观察可以发现, 每个 dp 值只和前一个 dp 值相关, 所以我们可以使用一个变量来节省空间, 然后从小到大遍历到 n 即可
- 而 dp 初始值为 n=1 的情况, 此时最后剩余的成员显然只能是 0

#### 复杂度

- 时间复杂度 O(N): 只需要遍历到 N
- 空间复杂度 O(1): 只使用了常数个变量

#### 代码

```python
class Solution:
    def iceBreakingGame(self, num: int, target: int) -> int:
        # 初始dp[1,target]为0
        dp = 0
        for x in range(2, num + 1):
            # 对应公式dp[x,target] = (dp[x-1,target] + target) % x
            dp = (dp + target) % x
        return dp
```
